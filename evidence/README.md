# Evidence

Verified claims live here as YAML records (`ev_*.yaml`), not as raw source dumps.

- Prefer hashes + excerpts + source_id over full-text.
- Status must be one of: unverified, verified, conflicted, rejected.
- A skill change without at least one verified evidence record is Risk B+ and should not auto-merge.
